# Mayous

マウスの**同時押し**をショートカットに変える、Windows のタスクトレイ常駐ツールです。

たとえば「右クリックを押しながら左クリック」で Windows キー、
「右クリックを押しながらホイール」で左右スクロール、というように使えます。

- 動作環境: Windows 10 / 11（64bit）。追加のランタイムは不要です
- インストール不要・管理者権限不要（UAC の確認は出ません）
- **レジストリは一切使いません**

> 開発者向けの情報（実装の背景・ビルド手順・テスト）は [DEVELOPMENT.md](DEVELOPMENT.md) にあります。

## 最初から入っている割り当て

| 操作 | 動作 |
|---|---|
| 右クリックを押しながら左クリック | Windows キー |
| 右クリックを押しながら中クリック | Alt+Tab |
| 右クリックを押しながらホイール下 | 右へスクロール（上に回すと左へ） |

すべて設定画面から変更できます。

**左クリックは一切触りません。** 「先に押す側」にはできない仕様です。理由は後述の
「[左クリックを「先に押す側」にはできません](#左クリックを先に押す側にはできません)」を
読んでください。

---

## 使い方

1. `mayous.exe` を好きな場所に置いてダブルクリックすると、タスクトレイに常駐します。
   専用のフォルダを 1 つ作ってそこに置いておくと、あとで片付けるのが楽です。
2. 設定は exe と同じ場所の `mayous.ini` に保存されます。
3. **トレイアイコンをダブルクリック**すると設定画面が開きます。

トレイアイコンをシングルクリック（左右どちらでも）するとメニューが出ます。

常駐中にもう一度 `mayous.exe` を起動すると、設定画面が開きます（二重には起動しません）。

| 項目 | 内容 |
|---|---|
| 設定... | 設定画面を開く |
| 有効 | 全機能の ON / OFF |
| 設定ファイルを開く | `mayous.ini` をメモ帳で開く |
| 設定を再読み込み | 手で編集した内容を反映する |
| バージョン情報 | 割り当ての保存先などを表示 |
| 終了 | 常駐を終了する |

## 割り当てられる組み合わせ

**先に押すボタン**は 右・サイドボタン1・サイドボタン2 の 3 つ。
そこへ **後から押すもの**として 左・右・中・サイドボタン1・サイドボタン2・
ホイール上・ホイール下 の 7 つを組み合わせられます（自分自身との組み合わせを除いて **18 通り**）。

さらに **登録キー** として、キーボードのキーを「後から押すもの」にできます。
たとえば「右クリックを押しながら **F13**」で「タブを閉じる（Ctrl+W）」といった具合です。
どのキーを使うかは自分で登録します（[登録キー](#登録キー)を参照）。

さらに**サイドボタンと中ボタンは、単独で押したときの動作も差し替えられます**。
たとえば「サイドボタン1 を押したらコピー」「サイドボタン1 で中クリック」
「中ボタンでオートスクロール」のような使い方ができます。

中ボタンは「先に押す側」にはできません（押しっぱなしにする用途が無く、
オートスクロールと衝突するため）。「後から押す側」としては使えます。

## 設定画面

タブで「先に押すボタン」を選び、その組み合わせに機能を割り当てます。

```
┌ 右クリック │ サイドボタン1 │ サイドボタン2 │ 中クリック │ 停止する条件 ┐
│  単独クリック   [そのまま (本来のクリック)  ▼] [記録]     │  ← サイドボタンのみ
│  + 左クリック   [なし                      ▼] [記録]     │
│  + 右クリック   [なし                      ▼] [記録]     │
│  + 中クリック   [なし                      ▼] [記録]     │
│  + サイドボタン2[なし                      ▼] [記録]     │
│  + ホイール上   [なし                      ▼] [記録]     │
│  + ホイール下   [なし                      ▼] [記録]     │
│  + 登録キー1 [F13] [タブを閉じる (Ctrl+W)  ▼] [記録]     │
└───────────────────────────────────────────────────────────┘
```

割り当ての指定方法は 2 通りあります。

### 1. 一覧から選ぶ

ドロップダウンから選ぶだけです。約 40 種類が用意してあります。

- **ウィンドウ操作** … Windows キー / Alt+Tab / タスクビュー / デスクトップを表示 /
  最大化・最小化 / 左右に寄せる / 仮想デスクトップの切り替え / ウィンドウを閉じる
- **スクロール** … 水平ホイール（左 / 右）
- **ブラウザ・タブ** … 戻る / 進む / 更新 / 全画面 / 新しいタブ / タブを閉じる /
  閉じたタブを復元 / 次のタブ / 前のタブ
- **編集** … コピー / 貼り付け / 切り取り / 元に戻す / やり直し / すべて選択 /
  保存 / 検索 / 削除
- **メディアほか** … 音量の上下 / ミュート / 再生・一時停止 / 次の曲 / 前の曲 /
  エクスプローラー / スクリーンショット / アプリキー

### 2. キー入力を記録する

**[記録]** ボタンを押すと記録画面が開きます。割り当てたいキーを実際に押すだけです。

- 同時に押した一組が 1 ステップになります（例: `Ctrl` + `Shift` + `K`）
- 続けて別のキーを押すと 2 ステップ目になり、**順番に再生**されます
  （例: `Ctrl+C` のあと `Ctrl+V`）
- 最大 8 ステップまで

記録中はキーボードが一時的に効かなくなります（`Alt+Tab` や Windows キーを押したときに
Windows 側が反応してしまわないようにするためです）。**マウスは常に効く**ので、
[キャンセル] や [OK] はいつでも押せます。

一覧に無いものは、ドロップダウンに `ctrl+shift+f12` のように直接入力することもできます。

### オートスクロール

「中クリック」タブで単独クリックに **オートスクロール** を割り当てると、
**中ボタンを押して離した時点でスクロール・モードに入ります**。

- モード中は**カーソルがその場に止まり**、マウスを動かすとその移動量が
  そのままスクロールになります（縦も横も）
- **もう一度クリックする**か **Esc** で抜けます
- 入った場所に丸い目印が出ます。カーソルが動かなくなるので、
  今その状態であることが分かるようにするためです
- 速さは同じタブで調整できます（大きいほど速い。既定 100%）

この割り当てをすると、**中ボタン本来のクリックは無くなります**（押して離すのが
モードの入口になるため）。中クリックが必要なら、サイドボタンの単独クリックに
**中クリック**を割り当ててください。X-Mouse Button Control の
「オートスクロール（Change Movement to Scroll）」と同じ考え方です。

### 登録キー

各タブの一番下にある **登録キー1** の行では、マウスのボタンと組み合わせる
**キーボードのキー**を自分で決められます。

1. 行の左にある **[未設定]** ボタンを押します
2. 組み合わせたいキーを 1 つ押します（例: `F13`）。ボタンの表示がそのキーになります
3. 右のドロップダウンで、そのときの動作を選びます（例: タブを閉じる (Ctrl+W)）

これで「右クリックを押しながら F13」でタブが閉じるようになります。
発火のしかたはボタン同士の同時押しとまったく同じで、動作に割り当てたキーは
**マウスのボタンを離すまで押しっぱなし**になります。

- 登録キーは **タブごとに別々**です。「右クリック + F13」と
  「サイドボタン1 + F13」に違う動作を割り当てられます。
- マウスのボタンを押していないときは、そのキーは**何も変わらず素通し**します。
  普段使わないキー（`F13`〜`F24` など）を選んでおくと安心です。
- 登録を消したいときは、[記録] の画面で**何も押さずに [OK]** を押します。
- **登録キーを 1 つも使っていない間は、キーボードには一切触りません**
  （キーボードフック自体を張りません）。

### 割り当てたキーは、押している間ずっと押されたままになります

同時押しで発火したキーは、**先に押したボタンを離すまで押しっぱなし**になります。
右クリックを押しながら左クリックで Windows キーを割り当てたなら、右クリックを
押している間ずっと Windows キーも押されたままで、右クリックを離すと同時に離されます。

これが既定の動作なので、特別な指定は要りません。拡大鏡のような
「押している間だけ効く」タイプのアプリとも、そのまま組み合わせられます。

- **キーは連打されません。** 注入した押下に Windows がオートリピートを足すことは
  ないので、`Ctrl+W` を押しっぱなしにしてもタブが次々に閉じたりはしません
  （1 回押したのと同じです）。
- **`Alt+Tab` は押している間ウィンドウ一覧が出たままになり、離すと切り替わります。**
  本来の `Alt+Tab` と同じ挙動です。
- **複数ステップの記録**（`Ctrl+C` のあと `Ctrl+V` など）は、押しっぱなしに
  しようがないので順番に再生されます。
- **サイドボタンの単独クリック**は、ボタンを離した時点で発火するため
  同じく一瞬の打鍵になります。

一瞬で同時押しを終えた場合でも、`mayous.ini` の `KeyHoldMs`（既定 120ms）の
あいだは押されたままになります。これは上限ではなく「最低でもこれだけは押す」
という下限です。

ボタンを押したまま**同じ組み合わせをもう一度**成立させた場合（ホイールを
同じ方向へ回し続けるなど）は、いったん離してから少し間を空けて押し直します。
離した瞬間が見えないと「押しっぱなしのまま」に映り、2 回目以降が無かったことに
なるためです。**別のキーへ切り替わる場合は間を空けません**ので、ホイール上下に
別々のキーを割り当てておくと、回した瞬間に出ます。

この間隔は設定画面の「同じキーの押し直し」から
**120ms / 80ms / 40ms / 20ms** の 4 段階で選べます（`mayous.ini` では
`RepressGapMs`）。長いほどポーリング方式のアプリに確実に届き、短いほど速く
出ます。実測（ホイールを回してから、その押下が届くまで）:

| 設定 | 2 回目以降の遅れ |
|---|---|
| 120ms（既定） | 約 127ms |
| 80ms | 約 96ms |
| 40ms | 約 49ms |
| 20ms | 約 34ms |

20ms でも 34ms かかるのは、この待ちを Windows のタイマーで測っているためです
（分解能が約 15.6ms あるので、それより細かくは刻めません）。

> 古い設定ファイルにある `hold:f13` のような書き方もそのまま使えます。
> 今はどちらも同じ意味です。

**[OK] または [適用] を押した時点ですぐ反映されます。** 再起動は要りません。
[適用] は変更があるときだけ押せるようになり、適用し終わるとまた押せなくなります。

### 配色

設定画面は **Windows のライト／ダーク設定に自動で合わせます**。
切り替えたときも開いたまま追従します。
固定したい場合は `mayous.ini` の `[General]` にある `Theme` を
`light` または `dark` にしてください（既定は `system`）。

### そのほかの設定

| 項目 | 内容 |
|---|---|
| 各ボタンの長押し | この時間押しっぱなしにすると、同時押しを諦めて本来の押下に戻します |
| ドラッグと判定する距離 | この距離を超えて動かすと、本来のドラッグとして扱います |

全機能の ON / OFF は**トレイアイコンのメニュー**にあります（設定画面からは外しました）。

### 停止する条件

指定したウィンドウが前面にいるあいだ、mayous は全機能を止めます。
「停止する条件」タブで設定します。

```
┌ 停止する条件 ────────────────────────────────────┐
│ [ ] フルスクリーンのアプリが前面のときは停止する      │
│ 止める条件 (1 行に 1 つ)                             │
│ ┌──────────────────────────────────────────────┐   │
│ │ valorant.exe                                 │   │
│ │ title:Minecraft*                             │   │
│ └──────────────────────────────────────────────┘   │
│ 今開いているウィンドウ                     [更新]    │
│ ┌──────────────────────────────────────────────┐   │
│ │ Minecraft* Forge 26.1.1 - ...  [javaw.exe]   │   │
│ │ ATLauncher Console             [javaw.exe]   │   │
│ └──────────────────────────────────────────────┘   │
│ [実行ファイル名を追加]  [ウィンドウ名を追加]         │
└──────────────────────────────────────────────────┘
```

書き方は 1 行に 1 つ、2 種類だけです。

| 書き方 | 意味 |
|---|---|
| `valorant.exe` | 実行ファイル名 |
| `title:Minecraft*` | ウィンドウ名。`*` は「任意の文字列」 |

**`*` の位置で一致のしかたが決まります。** 大文字小文字は区別しません。

| 例 | 一致するもの |
|---|---|
| `title:Minecraft` | ウィンドウ名がちょうどこれ（完全一致） |
| `title:Minecraft*` | `Minecraft` で始まるもの（前方一致） |
| `title:*メモ帳*` | どこかに `メモ帳` を含むもの（部分一致） |

**なぜウィンドウ名が要るのか。** `java.exe` / `javaw.exe` のように、1 つの
実行ファイルがまったく別のアプリのウィンドウを何枚も出すことがあります。
Minecraft とそのランチャがまさにそれで、実行ファイル名で止めると両方
止まってしまいます。ウィンドウ名なら片方だけを狙えます。

**打ち込まなくても足せます。** 下の一覧に今開いているウィンドウが
「ウィンドウ名  [実行ファイル名]」の形で並ぶので、選んで
[実行ファイル名を追加] か [ウィンドウ名を追加] を押すだけです。
ウィンドウ名で足すと末尾に `*` が付いた前方一致になります。版やファイル名で
後ろが変わっても効くよう、`title:Minecraft*` くらいまで短くしておくと確実です。

判定は 1 秒ごとに行うので、**ウィンドウ名が変わればすぐ追随します**
（同じアプリの中でタイトルが変わる場合も含みます）。

## 知っておいてほしいこと

### 通常の右クリックは「離した瞬間」に発火します

押した瞬間には、それが修飾キー役なのか通常のクリックなのか判別できないためです。
素早くクリックする分には体感できませんが、原理上そうなっています。

### 左クリックを「先に押す側」にはできません

あるボタンを「先に押す側」にすると、**そのボタンの押下は離すまでアプリに届きません**
（同時押しかどうかが、離すまで確定しないためです）。

右クリックやサイドボタンならほとんど気になりませんが、**左クリックは別格**です。
ウィンドウの切り替えもドラッグの起点も左クリックなので、遅れがそのまま
「反応が鈍い」「枠を掴み損ねる」として体感に出ます。

以前は設定画面に「左クリック」タブがありましたが、**動作の安定を優先して
v13 でいったん取りやめました**。左クリックは mayous をまったく通らないので、
遅延はゼロです。`mayous.ini` に `LeftThen...` と書いても読み飛ばされます。

**「後から押す側」としてはこれまでどおり使えます。** 既定の
「右クリックを押しながら左クリック = Windows キー」はそのままです。

### ゲームには使わないでください

アンチチートが低レベルフックを不正ツールとみなす可能性があります。
既定で「フルスクリーンのアプリが前面のときは停止する」が ON になっていますが、
ボーダーレスウィンドウのゲームなどは、「停止する条件」タブに実行ファイル名か
ウィンドウ名を足しておいてください。

### 管理者権限で動いているウィンドウの上では効きません

タスクマネージャーやデバイスマネージャーなどが該当します。Windows の保護機構に
よるもので、回避するには mayous 自身を管理者として実行する必要があります。
UAC の昇格画面や Ctrl+Alt+Del の画面でも動作しません。

### ほかのツールに mayous のキーを渡したいとき

mayous が出すキーは、Windows から見て**正規の低レベル入力**です（キーボードフックにも
キー状態にも現れます）。ただし OS が必ず「注入された入力」という印を付けるので、
それを弾く作りのアプリには届きません。これは仕様上どうにもなりません。

もう一つ、**押している時間**が問題になることがあります。キーボードフックを張らず、
キーの状態を一定間隔で見に行く作りのアプリ（ゲームや拡大鏡など）は、押下時間が
短すぎるキーを丸ごと取りこぼします。

同時押しに割り当てたキーは**先に押したボタンを離すまで押しっぱなし**になるので、
相手の周期がどれだけ伸びていても必ず観測されます。押しっぱなしにできない場合
（複数ステップ・サイドボタンの単独クリック）と、同時押しが一瞬で終わった場合だけ
`mayous.ini` の `KeyHoldMs`（既定 120ms、1〜2000ms）が効きます。取りこぼされる
ようなら伸ばしてください。

### ほかのマウス常駐ソフトと併用しないでください

X-Mouse Button Control のような同種のツールや、MouseGestureL.ahk、
Logitech G HUB・Razer Synapse などのボタン割り当て機能と同時に使うと、
どちらが先にボタンを横取りするかで挙動が不安定になります。
特に**サイドボタンはこれらに奪われていることが多い**ので、mayous で使う場合は
先方の割り当てを外してください。

具体的に、次のことが起こります。

- **サイドボタンが別のボタンに化ける。** 先方がサイドボタン1 を中クリックや
  「戻る」に差し替えていると、mayous の設定を「なし」にしても、その差し替えは
  そのまま効きます。mayous を終了させて確かめてみてください。それでも同じなら
  mayous は無関係です。
- **mayous が保留しているボタンの離上を、先方が先に食べてしまうことがある。**
  そうなると mayous はいつまでも「まだ押されている」と思い込み、以後のクリックを
  同時押しの相方として飲み込み続けます。**v9 からは、押されているかどうかを
  フックとは別の経路（Raw Input）でも見張るようにしたので、この状態からは
  自動的に復帰します**（保留していたクリックも失われません）。
  それ以前の版では mayous を再起動するまで直りませんでした。

なお「先に押すボタン」に割り当てがある以上、mayous はその押下をいったん
預かります。組み合わせを「なし」にした場合は、預かった押下をその場で
**注入し直して**から後のボタンを通します。この注入は先方のツールからは
「いきなり押された」ように見えるため、ジェスチャー系のツールとは相性が
よくありません。**先方に任せたいボタンは、mayous 側では「先に押すボタン」
そのものを使わない**（そのタブの割り当てを全部「なし」にする）のが確実です。

### そのほかの制限

- 右ドラッグは、設定した距離を超えるまで押下が世に出ません。3D ビューの回転などでは
  最初の数ピクセルが失われます。
- マウスの左右ボタン入れ替え設定には未対応です。
- 全画面かどうかの判定はウィンドウの大きさで行うため、タスクバーを自動的に隠す
  設定では最大化ウィンドウを全画面と誤判定することがあります。

## 設定ファイル

設定画面を使わず `mayous.ini` を直接編集することもできます（編集後は
トレイメニューの「設定を再読み込み」で反映されます）。

```ini
[Chords]
; キー名は <先に押すボタン>Then<後から押すもの>
;   先に押す: Right / Side1 / Side2
;   後から  : Left / Right / Middle / Side1 / Side2 / WheelUp / WheelDown / Key1
RightThenLeft=win
RightThenMiddle=alttab
RightThenWheelDown=hwheel_right
RightThenWheelUp=hwheel_left
Side1ThenLeft=ctrl+shift+k, f9

; 登録キー: ...Trigger に書いたキーが、そのタブの「登録キー1」になる
RightThenKey1Trigger=f13
RightThenKey1=ctrl+w

; 書かれていない組み合わせは none
; LeftThen... は読み飛ばされる(左クリックは先に押す側にできない)

[Exclude]
; 前面に来たら止める条件。番号を振って 1 行に 1 つ
Rule1=valorant.exe
Rule2=title:Minecraft*

[Single]
Side1Alone=click:middle  ; サイドボタン1 を中クリックにする
Side2Alone=passthru      ; passthru = 本来のボタンとしてそのまま通す
MiddleAlone=autoscroll   ; 中ボタンでオートスクロール

[General]
AutoScrollSpeed=100      ; オートスクロールの速さ(%)。大きいほど速い

[General]
Theme=system             ; 設定画面の配色: system / light / dark
```

| 書ける値 | 意味 |
|---|---|
| `none` | 何もしない。**そのボタンを一切乗っ取らない** |
| `passthru` | 単独クリック用。本来のボタンとしてそのまま通す |
| `hwheel_left` / `hwheel_right` | 水平ホイール |
| `autoscroll` | 押して離すとスクロール・モードに入る（中ボタン向け） |
| `click:middle` | 中クリックを出す（`middleclick` とも書ける。`left`/`right`/`side1`/`side2` も可） |
| `win` / `alttab` / `alttab_back` | よく使うものの別名 |
| `ctrl+w`, `alt+left`, `win+d`, `f5` … | 任意のキーコンボ |
| `ctrl+c, ctrl+v` | カンマ区切りで複数ステップ（これだけは順に再生） |
| `hold:f13` | 古い書き方。`f13` と同じ意味（押しっぱなしは今や既定） |

修飾子は `ctrl` `alt` `shift` `win`。キーは `a`〜`z` `0`〜`9` `f1`〜`f24`
`tab` `enter` `esc` `space` `backspace` `delete` `insert` `home` `end`
`pageup` `pagedown` `left` `right` `up` `down` `apps` `printscreen`
`numpad0`〜`numpad9` `volumeup` `volumedown` `volumemute`
`medianext` `mediaprev` `mediaplay` `browserback` `browserfwd` ほか。

**あるボタンの割り当てを全部 `none`（単独は `passthru`）にすると、そのボタンには
一切手を触れません。** 左クリックは常にこの状態で、完全に素通しになります。

**設定ファイルは必ず exe と同じフォルダに作られます。** 別の場所へは逃がしません。
フォルダごと消せば設定も一緒に消える、という分かりやすさを優先しています。
Program Files のような書き込めない場所に置いた場合は起動時にその旨を知らせます
（書き込める場所へ移してください）。

## アンインストール

**Mayous はレジストリに一切書き込みません。** フォルダごと削除すれば終わりです。
自動起動の登録も行いません（スタートアップに入れるかどうかは使う人が決めることなので、
こちらからは何もしません）。自分でショートカットを置いた場合は、それも削除してください。

なお Windows は、Mayous に限らず**どんな exe に対しても**「起動した」「トレイアイコンを
出した」といった記録をレジストリに残します（`MuiCache`、`AppUserModelId` など）。
これは Mayous が書いたものではなく、こちらから止めることはできません。
気になる場合は、同梱のスクリプトでまとめて掃除できます。

```powershell
powershell -ExecutionPolicy Bypass -File tools\uninstall.ps1 -WhatIf   確認だけ
powershell -ExecutionPolicy Bypass -File tools\uninstall.ps1           実行
```

タスクマネージャーなどで強制終了すると、Windows が「異常終了」の記録を残します。
トレイメニューの「終了」で正常に終わらせれば残りません。
